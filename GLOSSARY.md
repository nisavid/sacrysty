# Sacrysty

Accepted names for the public cryptographic-operations context.

## Language

**Sacrysty**:
The project and institution for the public reusable cryptographic-operations
product.
_Avoid_: crypto-ops, Cryptosacristy

**Sacrystan**:
The public-facing, human-facing operator surface.

**`sacryd`**:
The prospective command name, pronounced “sacred.”
