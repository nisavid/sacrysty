# Architecture decision records

Normative or security-boundary changes require an ADR. Each record should state
the context, decision, alternatives, compatibility and migration consequences,
conformance changes, threat-model impact, and status.

Accepted records:

- `0003-maintained-dco-github-app.md` selects the maintained hosted DCO GitHub
  App for contribution enforcement.

The provenance handoff links the pre-repository decisions that constrain
future work.
