# Architecture decision records

Normative or security-boundary changes require an ADR. Each record should state
the context, decision, alternatives, compatibility and migration consequences,
conformance changes, threat-model impact, and status.

- [ADR 0001](0001-public-domain-model.md) records the accepted public-record
  domain model and inert-extension boundary.
- [ADR 0002](0002-genesis-integration-boundary.md) proposes the genesis
  integration boundary and requires review and maintainer approval.

The provenance handoff links the pre-repository decisions that constrain this
work.
