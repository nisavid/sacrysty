# Issue tracker

Issues and Wayfinder maps live in this repository's GitHub Issues. Use the
GitHub CLI for read and write operations.

The issue labelled `wayfinder:map` is the canonical implementation route. Its
child issues and native blocked-by relationships define the frontier. Claim a
ticket by assigning it to the driving developer before work. Record a
resolution comment, update the map's decision index when applicable, and close
the ticket last.
