# Policy profiles

This directory is reserved for public, non-secret policy profiles after the
owning contract work settles their identity, versioning, compatibility, and
schema.

Private deployment bindings, exact adopter locks, resolved secret values, host
configuration, and acceptance evidence do not belong here. The reusable signing profile is published in [signing-v1.md](signing-v1.md). It is value-free and limited to the RFC 9580 support boundary documented there.
